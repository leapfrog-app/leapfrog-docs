# Analytics

Visualize and filter coded research data to identify patterns and relationships.

## Access

Open analytics from the Codes page in a workspace.

## Chart types

- **Bar Chart**: Tag frequency counts
- **Bubble Chart**: Tag distribution with proportional bubbles
- **Network Chart**: Relationships and co-occurrence between tags

## Filtering

Filter by:

- **Tags**: Focus on specific tags or groups
- **Document fields**: Filter by metadata (demographics, dates, etc.)
- **Date range**: Restrict to specific time periods
- **Combined criteria**: Multiple filter conditions

## Tag relationships

Network charts show connections between tags. Thicker lines indicate stronger relationships. Clusters represent related tag groups.

## Exploring highlights

Click any tag or data point to view associated quotes. The highlights panel shows full context. Click a highlight to navigate to its source document.

## Exporting

Use browser screenshot tools to capture visualizations. Export data to CSV for external analysis.
