## Prerequisites

- Node.js (version 18.10.0 or higher) must be installed.

## Local Preview

1. Install Mintlify globally:
   - Using npm:
     ```bash
     npm i -g mintlify
     ```
   - Using yarn:
     ```bash
     yarn global add mintlify
     ```
2. Navigate to the directory containing your documentation (where `mint.json` is located).
3. Start the local development server:
   ```bash
   mintlify dev
   ```
   The documentation website will be available at `http://localhost:3000` by default.

### Custom Ports

- To use a custom port, add the `--port` flag:
  ```bash
  mintlify dev --port 3333
  ```
- If the port is already in use, you will see an error similar to:
  ```
  Error: listen EADDRINUSE: address already in use :::3000
  ```

## Updating Mintlify CLI

- To update the CLI to the latest version:
  - Using npm:
    ```bash
    npm i -g mintlify@latest
    ```
  - Using yarn:
    ```bash
    yarn global upgrade mintlify
    ```

## Troubleshooting

- **Mintlify is not loading:**
  - Update to Node v18 or higher.
  - Run `mintlify install` and try again.
- **No such file or directory on Windows:**
  - Go to `C:/Users/Username/.mintlify/` and remove the `mint` folder.
  - Open Git Bash in this location and run:
    ```bash
    git clone https://github.com/mintlify/mint.git
    ```
  - Repeat the local preview steps.
- **Unknown error:**
  - Navigate to the root of your device and delete the `~/.mintlify` folder.
  - Run `mintlify dev` again.

For CLI version changes, see the [CLI changelog](/changelog/command-line).
