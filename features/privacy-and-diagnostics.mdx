Leapfrog keeps privacy controls in the desktop app instead of treating them as a hidden backend detail.

## Diagnostics is optional

The current desktop control is **Privacy & Diagnostics** in Leapfrog Settings.

Diagnostics is:

- off until you explicitly allow it
- stored as a local desktop preference
- available to review and change later in settings

## What the setting covers

Diagnostics is intended for optional crash reporting and performance tracing that helps debug desktop issues.

If you do not enable it, Leapfrog keeps diagnostics disabled.

## When you will see it

If the preference is unset, Leapfrog can prompt once so you can choose whether to allow diagnostics. You can still change that decision later from settings.

## Practical guidance

Turn diagnostics on when you are:

- testing a new build
- reporting a bug
- working with the team on a desktop issue

Leave it off if you do not want the extra reporting.
