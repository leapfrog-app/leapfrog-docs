title: Favorites
description: 'Keep the small set of files you revisit most in a dedicated Explorer view.'
---

Favorites is a simple but useful feature when you are constantly jumping between the same files.

## Add a favorite

Right-click any file in Explorer and choose **Favorite/unfavorite**.

Once at least one file is favorited, Leapfrog shows a **Favorites** view in Explorer.

## What Favorites is for

Use it for:

- the current transcript you are coding
- the synthesis note you update every day
- the project brief or study plan
- exported reports you keep cross-checking

## How it behaves

- clicking a favorite opens the file
- removing the favorite only removes the shortcut, not the file
- the view disappears again when no favorites remain

Favorites is intentionally small. It is not a second file tree. It is a fast shortlist for the files that matter right now.
