# Collaboration

Multiple users can work together in real time across workspaces, documents, and canvases.

## Workspace sharing

### Inviting members

1. Open **Workspace Settings > Sharing**
2. Enter email addresses
3. Assign permission levels
4. Send invitations

Invited users receive an email link to join.

### Permission levels

- **Owners**: Full access including settings and deletion
- **Editors**: Create, edit, and delete content
- **Viewers**: View-only access (if available on your plan)

### Managing members

View current members in **Workspace Settings > Sharing**. Change permissions or remove members.

## Real-time editing

### Documents

Multiple users can edit the same document simultaneously. See who's viewing or editing. Changes sync instantly.

### Canvas

Users can add or move items on the canvas simultaneously. Changes sync in real time.

## Comments

Add comments to text or elements using the comment icon in the toolbar. Comments are visible to all team members and can be resolved.

## Best practices

- Define roles and responsibilities
- Standardize naming conventions
- Use document fields consistently
- Align on coding strategies
- Record key research decisions
