# Quotes and Tags

Label and organize segments of research data for analysis.

## Creating quotes

1. Select text in your document
2. Click the quotation button in the toolbar
3. The text is marked as a quotation

Optionally add a tag immediately or tag it later.

## Creating tags

Tags categorize quotes into groups:

1. Select text
2. Click the tag button in the toolbar
3. Choose an existing tag or create a new one (name and color)
4. The text is tagged

## Managing codes

All tags are accessible from the Codes page:

- View all tags in your workspace
- See tag frequency and distribution
- Rename, merge, or delete tags
- Filter by tag or document field

## Visualization

Analyze coded data:

- **Tag charts**: View tag distribution and frequency
- **Tag lists**: Browse quotes by tag
- **Field filtering**: Filter tags by document field values

Filter by tag, document field, or date range to identify patterns.
