# Guided-AI Coding

## What is Guided Coding?

Guided coding automatically analyzes and tags your research data based on custom examples you provide. The AI follows your team's coding patterns and terminology to ensure consistent analysis across your research.

## Workspace-Level Settings

### Customization Per Workspace

Each workspace has unique coding settings to match your team's conventions and research focus.

**Workspace-level settings include:**

- **Default Prompt/Instructions:** Custom instructions and examples that define your coding style and terminology
- **Interest Threshold:** A sensitivity setting (1–10) that controls how "interesting" text must be to be tagged. Higher values result in fewer, more insightful tags.

These settings are managed in workspace settings and apply as defaults for all guided coding operations.

## How Code Generation Works

### The Guided Coding Pipeline

1. **Data Extraction:**

   - Identifies distinct semantic blocks of text (speech bubbles, paragraphs, conversation turns)

2. **Interest Evaluation:**

   - Evaluates text against the workspace's interest threshold
   - Only codes text above the threshold (if enabled)

3. **Code Generation:**

   - Matches existing codes using semantic similarity
   - Creates new codes following these rules:
     - Short and concise (max 5 words, under 25 characters, no punctuation)
     - Includes brief description (under 100 characters)
     - Optionally identifies key segment for partial highlighting

4. **Highlighting:**

   - Highlights relevant text segments in the document

5. **Tag Management:**
   - Deduplicates and stores codes as tags
   - Groups highlights by tag and document

## Customizing AI Behavior

The instructions you provide directly control the AI's coding behavior. You can:

- Focus on specific types of codes (pain points, suggestions, feedback)
- Set coding style and tone
- Define which content to prioritize or ignore

For best practices on writing effective prompts, see the [few-shot examples guide](https://www.promptingguide.ai/techniques/fewshot).
