# AI-Guided Coding

Automatically analyze and tag research data based on custom instructions and examples.

![AI-Guided Coding Interface](/images/auto-coding.png)

## Setup

Configure in **Workspace Settings > Coding**:

- **Default Instructions**: Define coding methodology and terminology
- **Interest Threshold** (1-10): Controls sensitivity for tagging
  - Higher (7-10): More selective, fewer tags
  - Medium (4-6): Balanced
  - Lower (1-3): More inclusive, more tags

## Usage

After configuration, AI-guided coding:

1. Analyzes documents and identifies relevant segments
2. Creates or applies tags following your patterns
3. Highlights tagged text in documents
4. Stores tags at the workspace level

Review and refine AI-generated tags in the document view.

## Tag format

AI-created tags follow these rules:

- Concise (max 5 words, under 25 characters)
- No punctuation
- Brief description (under 100 characters)

## Best practices

- Provide clear, specific instructions
- Include 3-5 examples of correctly tagged content
- Adjust interest threshold based on results
- Review and refine AI tags as needed
- Combine AI coding with manual refinement
