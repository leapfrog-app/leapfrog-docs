# Document Editor

Create, edit, and collaborate on research documents. Multiple users can edit simultaneously with real-time sync.

## Formatting

Use the toolbar to format text:

- **Text styling**: Bold, italic, underline, strikethrough
- **Headings**: Multiple heading levels
- **Lists**: Bulleted and numbered lists
- **Code blocks**: For technical content
- **Links**: Add hyperlinks

![toolbar](/images/document-editor/toolbar.svg)

## Transcripts

Upload audio or video files to transcribe:

1. Click the waveform button in the toolbar
2. Upload your file
3. Configure transcription settings
4. Start transcription

Once complete, the transcript appears in your document where you can edit, tag, and analyze it.

## Document fields

Fields at the top of documents store structured metadata:

- **Text fields**: Short text values
- **Number fields**: Numerical data
- **Date fields**: Date selection
- **Switch fields**: Yes/no toggles

Manage fields in **Workspace Settings > Documents**. Changes apply to all documents in the workspace.

## Quotes and tags

Select text and use the toolbar to:

- Create quotes to mark important segments
- Add tags to categorize themes

View and manage all quotes and tags in the Codes page.

## Search

Use full-text search to find terms within the document. Navigate sections using headings or jump to tagged content.
