# Canvas

The Canvas in Leapfrog is a visual workspace for organizing, mapping, and analyzing qualitative research data. It enables users to create visual overviews, identify patterns, and leverage AI tools for clustering and summarization.

## Creating a Canvas

- Navigate to a workspace.
- Click **New Canvas** in the top right corner to create a blank canvas.

## Adding Data

- Use the **Add Data** button to select and drag documents or quotes onto the canvas.
- Each item becomes a data node that can be organized within the workspace.

## Canvas Elements

- **Data Nodes**: Represent individual pieces of information (e.g., quotes, insights) added from documents or imports.
- **Text Elements**: Add custom text for labels, notes, or context.
- **Paths**: Draw connections between data nodes to map relationships.
- **Notes**: Annotate data points or connections for additional context.
- **Themes**: Group related notes or data nodes. Themes can be created manually or generated automatically via AI clustering.

## AI Integrations

### Clustering

- Select multiple data nodes and use the **Cluster** option to group related items using AI.
- Each cluster is annotated by the AI to explain the grouping rationale.

### Summarization

- Select a cluster or data nodes and use the **Summarize** option to generate concise summaries and key takeaways using AI.

## Usage Steps

1. Select data nodes to analyze.
2. Use **Cluster** to group related data points.
3. Review AI-generated annotations for each cluster.
4. Select a cluster and use **Summarize** to generate a summary.
5. Refine summaries or request alternatives as needed.

## Benefits

- Reduces manual work in organizing and interpreting large datasets
- Provides transparency into AI-driven groupings and summaries
- Supports efficient identification of patterns and key insights
