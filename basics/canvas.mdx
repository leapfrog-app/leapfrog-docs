# Canvas

Visual workspace for organizing and analyzing research data.

## Creating a canvas

Click **New Canvas** in your workspace to create a blank canvas.

## Adding data

Use **Add Data** to select and drag documents or quotes onto the canvas. Each item becomes a data node.

## Elements

- **Data Nodes**: Quotes, insights from documents
- **Text Elements**: Custom labels, notes
- **Paths**: Connections between nodes
- **Notes**: Annotations on nodes or connections
- **Themes**: Groups of related nodes (manual or AI-generated)

## AI features

### Clustering

Select multiple nodes and use **Cluster** to group related items using AI. Each cluster includes AI annotations explaining the grouping.

### Summarization

Select a cluster or nodes and use **Summarize** to generate summaries and key takeaways.

## Workflow

1. Add data nodes to the canvas
2. Use **Cluster** to group related items
3. Review AI-generated annotations
4. Use **Summarize** to generate insights
5. Refine as needed
