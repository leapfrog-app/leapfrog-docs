# Chat

Chat lets you query your workspace data using natural language. The AI searches through documents, transcripts, and other workspace data to answer questions.

## Usage

Enter a question in the chat input. The AI analyzes the query and generates responses based on workspace content, including relevant quotes and excerpts.

## Document mentions

Mention specific documents to focus the AI on particular content.

**How to mention:**

1. Type `@` in the chat input
2. Select a document from the popover
3. Ask your question

You can mention multiple documents in one message. The AI uses the full content of all mentioned documents to answer.

## Custom instructions

Configure the AI's response style in **Workspace Settings > Chat**. Enter custom instructions to guide how the AI interprets and responds to queries.

## Agent skills

Leapfrog can also load reusable `SKILL.md` instructions from your workspace or user profile for tasks that benefit from a predefined workflow.

See [Agent Skills](/basics/agent-skills) for supported locations, discovery rules, and troubleshooting steps.
