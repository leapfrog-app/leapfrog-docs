# Integrations

Integrations connect external services to your workspace, allowing you to import files directly without manual downloads.

## Setup

Navigate to **Workspace Settings > Integrations** to view available integrations and their connection status.

### Connecting an integration

1. Open **Workspace Settings > Integrations**
2. Click **Connect** on the integration card
3. Authorize the connection when redirected
4. You'll be redirected back to the integrations page

Each user in a workspace manages their own integration connections.

### Disconnecting

1. Go to **Workspace Settings > Integrations**
2. Click **Disconnect** on the connected integration

Disconnecting doesn't affect files already imported—only prevents future imports.

## Available integrations

### Google Drive

**Supported file types:**

- Text: `.txt`, `.docx`, Google Docs
- Audio: `.mp3`, `.wav`, `.ogg`, `.aac`, `.webm`, `.flac`, `.m4a`
- Video: `.mp4`, `.webm`, `.ogv`, `.avi`, `.mov`, `.mkv`, `.wmv`

**Usage:**

- Import files via the "New Document" dropdown menu
- Select "Import from Drive" to open the Google Drive picker
- Choose a file to import

Text files and documents are converted to Leapfrog documents. Audio and video files are imported for transcription.

## Permissions

Only workspace Editors and Owners can connect integrations. Integration connections are visible to all workspace members but managed individually by each user.
